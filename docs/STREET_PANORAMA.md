# Панорама улицы

Файл: `public/assets/world/city-districts-panorama-v1.jpg`.
Исходник: `public/assets/world/city-districts-panorama-v1.png`.

Создано встроенным imagegen по референсу `city-background-plaza-v1.jpg`.
Промпт: единая панорама 3:1 вечернего города, четыре последовательных участка:
стеклянная набережная, библиотека, зимний сад, обсерватория. Общие горизонт,
освещение, непрерывные ограждение и мощёная площадка; передние участки пустые
для отдельных спрайтов зданий. Без текста, людей, зеркальных повторов и границ панелей.

На главной одна панорама занимает всю горизонтальную ленту, а не повторяется
в каждом доме. Здания используют полные игровые модули. Высота их видимой
области — 220px, как на экране завершения сессии. Новые темы остаются будущими
участками: смена декораций сама по себе не открывает учебный контент.
