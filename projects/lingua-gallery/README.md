# Lingua Gallery — самостоятельная языковая игра

## Играбельная версия · 30 сентября 2026

Запуск из этой папки: `npm run dev`, адрес http://localhost:5180.
Сборка: `npm run build`. На чистой машине сначала `npm install`.

Реализовано: семь магазинов, 28 выражений с иллюстрациями, знакомство со словами и озвучка средствами браузера, три последовательно открываемых уровня в каждой теме (узнавание, аудирование, сборка фразы), диалог в конце миссии, перемешивание ответов, игровые монеты, покупки, коллекция и полка на четыре вещи. Магазины: одежда, продукты, дом, кафе, путешествия, уход за собой, электроника. Ошибки сохраняются для повторения, без потери денег. Прогресс отдельный от «Планеты 5+», хранится локально на устройстве.

Это первый законченный игровой цикл, не весь коммерческий продукт из плана. Пока нет аккаунтов, синхронизации между устройствами, нативной оболочки, оплаты, полноценного интервального планировщика или записанной дикторской озвучки. Доступность синтеза речи зависит от браузера; предусмотрена текстовая подсказка. Сохраняются покупки, завершённые уровни и одна текущая миссия: слово, вопрос, порядок вариантов, выбранный ответ, подсказка и ошибки. Кнопка «Продолжить» восстанавливает её после перезагрузки. Начало другой миссии заменяет незавершённую; результаты прошлых миссий остаются.

Визуал: собственные иллюстрированные витрины и объёмные товары в единой тёплой палитре. Иллюстрации генерированы встроенным инструментом; прозрачные атласы товаров показываются через SVG с индивидуальными рамками. Одна заметная кнопка на каждом экране; выбор магазина и уровня — в дополнительном диалоге. Без внешних шрифтов. См. [реестр графики](ASSETS.md).

Проверки: `npm test` — сохранения, повторение, награды, покупки, порядок уровней и полнота контента. [Ревизия и оставшиеся ограничения](AUDIT.md).

Рабочее название, не проверенное на товарные знаки и домены. Дата плана: 29 сентября 2026.

Отдельный продукт для людей любого возраста: изучение языка через покупки, общение и развитие собственной торговой галереи. Не является детским разделом «Планеты 5+». Текущий English-магазин — прототип механики, а не готовая архитектура нового продукта.

**Обещание:** «Пять минут в своём городе — новые слова для настоящей жизни».

## Зафиксированные решения

1. Возрастная нейтральность: современный игровой мир, спокойный тон, доступность и регулируемая сложность.
2. Первый языковой маршрут: русский → английский, начинающий и возвращающийся уровень. Другие пары — после проверки спроса.
3. Web/PWA сначала; iOS и Android затем на общем учебном ядре.
4. Магазин — вход в жизненную ситуацию: понять, выбрать, спросить, ответить. Не только перевод существительных.
5. Ошибки не отнимают коллекцию. Исправление и повторение входят в основной игровой цикл.
6. Бесплатное ядро + подписка на расширение мира; покупка не повышает уровень знания языка.
7. Все цены, бюджеты, сроки и целевые метрики в документах — гипотезы для проверки, не прогнозы продаж.

## Что ещё предстоит выбрать

Финальное название и права на него; страна первого коммерческого запуска и продавец; бюджет команды; провайдеры платежей и инфраструктуры; необходимость детских аккаунтов на первом этапе. Эти решения не мешают сделать и проверить бесплатный веб-прототип.
