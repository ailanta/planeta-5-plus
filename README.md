# Планета 5+

Строй. Играй. Учись. Русская версия образовательного города.

Актуальный план бренда, районов и отдельных зданий тем: [docs/PLANETA_5PLUS.md](docs/PLANETA_5PLUS.md).

Мобильное веб-приложение для коротких игровых тренировок школьных тем. Первая игра — «Небоскрёб слов» по теме «Проверяемые безударные гласные в корне».

Главный документ для продуктовой и технической разработки: [docs/PROJECT_SPEC.md](docs/PROJECT_SPEC.md).

План нового дизайна и задачи для агентов: [Город знаний — объёмные здания и прокрутка улицы](docs/CITY_DESIGN_PLAN.md).

Статус: MVP в разработке; реализован первый рабочий вертикальный срез. Геометрия сцены и визуальные типы этажей вынесены в [`src/world.ts`](src/world.ts), контракт графических ресурсов — в [`public/assets/world/manifest.json`](public/assets/world/manifest.json). Максимальная высота активной башни рассчитывается из всей базы заданий с учётом коэффициентов ×1/×2. Активная тема использует рисованный городской фон, процедурный фундамент и соседний участок «＋» для выбора следующего мира.

Для визуальной проверки сцен в dev-режиме: `http://127.0.0.1:5173/?gallery=1`.

Игровой экран использует полноэкранную сцену башни с компактной карточкой задания выше центра. На широком экране сохраняется мобильный холст до 430 px. Новые районы и темы пока представлены анонсами; активна тема проверяемых гласных. Ключи хранения прежнего бренда сохранены для совместимости прогресса.

## Локальный запуск

~~~bash
npm install
npm run dev
~~~

Проверки:

~~~bash

~~~
